# Network-Based Prioritization of Secondary Metabolites from Orphan Biosynthetic Gene Clusters to Identify Candidate Enzymatic Modulators of JNK1 and IKKβ Involved in Insulin Resistance

This repository contains the code and supplementary materials for the manuscript "Network-Based Prioritization of Secondary Metabolites from Orphan Biosynthetic Gene Clusters to Identify Candidate Enzymatic Modulators of JNK1 and IKKβ Involved in Insulin Resistance" submitted to Network Modeling Analysis in Health Informatics and Bioinformatics (NetMAHIB).

## Repository Structure
* `/data`: Cleaned datasets and input files used for network analysis and molecular docking.
* `/scripts`: Custom Python scripts used for statistical analysis and data parsing.
* `/materials`: Configuration files for AutoDock Vina and other supplementary parameters.

## Prerequisites
* Python 3 (Google Colab)
* Packages used:
  * numpy, pandas, matplotlib, networkx, scipy, statsmodels, community, prettytable, collections, sklearn
